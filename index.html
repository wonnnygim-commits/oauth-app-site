운영자와 승인된 사용자의 Google Sheets 작업을 지원하는 개인용 자동화 도구입니다. 공개 회원가입 서비스가 아닙니다.

주요 기능

  • 사용자가 전달한 뉴스와 리서치 자료를 정리하여 지정한 시트에 기록
  • 기업 월매출 데이터와 관련 시트 갱신
  • 포트폴리오 시트의 지정된 수기 입력 셀 갱신과 보고 작성

Google 계정 연결

사용자 동의를 받은 OAuth 인증으로 Google Sheets를 읽고 수정하며, 파일 식별에 필요한 Drive 메타데이터를 조회합니다. 계정 확인을 위해 일부 연결에서 이메일·기본 프로필 권한을 사용합니다. 실제 접근은 승인된 권한과 파일 공유 권한에 따릅니다.

이 사이트는 앱 소개용입니다. Google 로그인이나 인증 코드를 입력받지 않으며, 사용자 시트·포트폴리오 데이터 또는 인증정보를 게시하지 않습니다.

개인정보처리방침 · 이용 안내

문의: Google OAuth 동의 화면에 표시된 사용자 지원 이메일 또는 운영자와의 기존 개인 연락 채널.
